# VLA from scratch: the site

The website for [vla-from-scratch](https://github.com/arianizadi/vla-from-scratch), a hands-on guide
to the models behind robot manipulation (language model, vision-language model, vision-language-action
policy). The experiments, the code and the field notes live in that repository; this one presents
them as chapters with animated explanations.

> **Status:** freshly scaffolded. No content yet.

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS. Planned: MDX for the chapters, Framer Motion
and GSAP for diagrams, SVG for figures, Three.js for replaying robot rollouts.

## Develop

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build

```bash
npm run build
```
